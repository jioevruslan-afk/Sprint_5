# Sprint_5

Автотесты на Selenium для учебного сервиса Stellar Burgers.

## Что проверяется

- регистрация пользователя;
- ошибка при некорректном пароле;
- вход через главную страницу, личный кабинет, форму регистрации и форму восстановления пароля;
- переход в личный кабинет;
- переход из личного кабинета в конструктор через ссылку и логотип;
- выход из аккаунта;
- переключение разделов «Булки», «Соусы», «Начинки» в конструкторе.

## Структура проекта

- `tests/` — тесты по функциональностям;
- `conftest.py` — фикстуры Selenium и ожиданий;
- `locators.py` — локаторы элементов;
- `helpers.py` — генераторы данных и общие действия;
- `requirements.txt` — зависимости проекта.

## Установка и запуск

```bash
pip install -r requirements.txt
pytest -v
```

Тесты запускаются в Google Chrome. Каждый тест открывает новый браузер и закрывает его после выполнения.
